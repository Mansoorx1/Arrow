# 🏹 Arrow Hell – Arrow Escape

A puzzle game where you tap arrows to let them escape the board. 50 levels, zero mercy.

🔗 **Play it live:** https://mansoorx1.github.io/Arrow/

## How to Play
- Tap an arrow whose path to the edge is clear.
- Clear every arrow to finish the level.
- You have limited **mistakes** (3 hearts) and **hints**, so think before you tap.

## Features
- 50 levels of increasing difficulty
- Hint system, restart and reset-save options
- Level select with unlocking, and you clear a level to open the next
- Progress saved on your device
- Mobile-friendly, built for thumbs

> Progress is stored in your browser. Clearing browser storage may erase it.

- HTML
